# ✦ Antigravity Custom Skills Hub

Kumpulan skill kustom resmi untuk Google Antigravity AI, dioptimalkan untuk kecepatan tinggi dan antarmuka ramah pengguna.

---

## 📦 Daftar Skill Tersedia

### 1. `computer-use` (Indonesian Edition + Cosmic Cyan Glow)
* **Warna Rona Antigravity:** Mengganti kilatan putih silau lama dengan **Cosmic Cyan Ambient Glow** (`#00E5FF`) yang adem dan futuristik di tepi layar.
* **Logo Antigravity:** Logo Bintang Kosmik / Diamond 4-Titik (✦) di kiri atas banner status.
* **Bahasa Indonesia:** Teks resmi `Antigravity sedang menggunakan laptop` dan tombol darurat `ESC - Berhenti` (100% bebas bahasa Rusia).
* **Performa Tinggi:** Terhubung ke micro-client `cu.exe` dan atomic clipboard paste.

### 2. `fast-gui-orchestrator`
* Menghilangkan latensi mikro-step (dilarang screenshot bertahap).
* Proteksi fokus jendela dan injeksi instan teks via clipboard.

## ⚡ Cara Pasang di Antigravity Teman (Mudah & Cepat)

Temanmu cukup membuka **PowerShell** di komputernya dan menjalankan 1 perintah ini:

```powershell
git clone https://github.com/cryptoandforex21th-beep/SecondBrain.git "$env:TEMP\sb_temp"; & "$env:TEMP\sb_temp\skills\install_skills.ps1"; Remove-Item -Recurse -Force "$env:TEMP\sb_temp"
```

Setelah itu, restart Antigravity IDE. Skill `computer-use` langsung aktif dengan tampilan baru di laptop mereka! 🚀
